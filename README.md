# Telomerecat Lite

**Telomerecat Lite** is a simplified version of [Telomerecat](https://github.com/cancerit/telomerecat), but it is more flexible for different sequencing platforms, such as:

- MGI (T7, G400)
- Illumina (NovaseqX, Novaseq6000)

---

Telomerecat Lite is a tool for estimating the average telomere length (TL) for a paired end, whole genome sequencing (WGS) sample. 

Telomerecat Lite is adaptable, accurate and fast. The algorithm accounts for sequencing amplification artifacts, anneouploidy (common in cancer samples) and noise generated by WGS. For a high coverage WGS BAM file of around 100GB telomerecat can produce an estimate in ~1 hour.

### Requirenments
* python=3.10
* gcc, gxx (for parabam compilation)

`pip` will install the relevant dependancies, listed here for convenience:

* [parabam](https://github.com/cancerit/parabam)
* [numpy](https://numpy.org/)
* [pysam](https://www.scipy.org/)
* [pandas](https://pandas.pydata.org/)

## Installation with conda env

```bash
git clone https://github.com/eamozheiko/telomerecat
cd telomerecat
conda create -n telomerecat python=3.10 gcc gxx
conda activate telomerecat
python setup.py develop # so bin scripts can find module
```
